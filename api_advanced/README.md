# api_advanced

Python scripts that query the Reddit API with the Requests module.

| File | Description |
|------|-------------|
| 0-subs.py | Number of subscribers of a subreddit |
| 1-top_ten.py | Titles of the first 10 hot posts |
| 2-recurse.py | Recursively lists all hot post titles |
| 3-count.py | Recursively counts keywords in hot titles |
